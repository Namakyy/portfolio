Project Summary EN

ATC Manager is a web-based air traffic control management application built as part of the SAÉ S2.03 module at IUT Réseaux & Télécommunications. The project was developed collaboratively by a team of three students over six weeks, using Django as the backend framework, MySQL as the database engine, and deployed on a Linux virtual machine running Apache.

The application allows operators to manage airports, runways, airlines, aircraft types, aircraft, and flights through a full CRUD interface. Its core feature is an automatic runway assignment algorithm: when a new flight is created, the system checks runway availability at both departure and arrival airports based on runway length compatibility and time-window conflicts and assigns a free runway automatically. If no runway is available at the requested time, the user is informed and must choose a different time slot.

The application also features a CSV bulk import for flights with per-line validation and a detailed import summary, and a report page allowing filtering by airport and date range. The entire frontend was designed with a custom dark aviation theme built from scratch.

Ce que cette SAÉ m'a vraiment appris :

La SAÉ RT3 est le projet le plus complet que j'ai réalisé en BUT. Ce qui m'a le plus appris, c'est la séparation des responsabilités dans un projet réel : l'algorithme dans services.py, les vues dans views.py, les formulaires dans forms.py. Avant, j'aurais tout mis dans un seul fichier sans me poser la question.

La gestion du dépôt GitHub en équipe a aussi été un apprentissage concret. Mettre en place des règles de protection et un workflow de PR n'est pas complexe techniquement, mais c'est ce qui a évité les conflits et les écrasements de code pendant les 6 semaines du projet.

L'algorithme de vérification de piste m'a confronté à un problème que je n'avais pas anticipé : la disponibilité d'une ressource dans le temps est un problème classique mais non trivial. Comment définir une fenêtre de conflit ? Comment gérer le cas où l'aéroport n'a aucune piste compatible en longueur ? Ces cas limites m'ont appris à penser à la robustesse avant même de coder.

Ce que je veux approfondir : les tests unitaires Django (TestCase) pour valider l'algorithme automatiquement, et l'intégration continue via GitHub Actions.
